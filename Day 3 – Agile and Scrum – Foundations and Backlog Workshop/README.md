Agile Scrum Training Assignments
This repository contains three Agile Scrum projects completed as part of the Hexaware training program. The projects focus on understanding Agile methodology, Scrum practices, product backlog creation, user story writing, prioritisation, story point estimation, and Jira project management.

Set 1: FreshCart – Online Grocery Delivery Application
FreshCart is an online grocery delivery application that allows customers to browse products, add items to their cart, place orders, and track deliveries.

Work completed:
- Created product vision.
- Identified Scrum roles and responsibilities.
- Created 3 epics and 12 user stories.
- Reviewed user stories using INVEST principles.
- Prepared Given, When, and Then acceptance criteria.
- Prioritised stories using MoSCoW.
- Estimated story points using Fibonacci Planning Poker.
- Prepared Definition of Ready and Definition of Done.
- Created and managed the project backlog in Jira.
Total Story Points: 41

Set 2: InsureAssist – Insurance Claims Portal
InsureAssist is an insurance claims portal that helps customers submit insurance claims, upload supporting documents, track claim progress, and receive settlement notifications.

Work completed:
- Created product vision.
- Compared Agile and Waterfall methodologies.
- Created 4 epics and 12 user stories.
- Reviewed user stories using INVEST principles.
- Prepared acceptance criteria.
- Prioritised and estimated the backlog.
- Used Fibonacci Planning Poker for estimation.
- Created a Jira Scrum project.
- Prepared a note explaining Scrum roles, events, and artifacts.
- Prepared Definition of Done.
Total Story Points: 45

Set 3: MediBook – Hospital Appointment Booking Application
MediBook is a hospital appointment booking application that allows patients to search for doctors, view available slots, book appointments, reschedule or cancel appointments, and receive reminders.

Work completed:
- Created 4 epics and 12 user stories.
- Prepared a prioritised product backlog.
- Used MoSCoW prioritisation.
- Estimated stories using Fibonacci story points.
- Prepared acceptance criteria.
- Reviewed user stories using INVEST principles.
- Created and managed the project in Jira.
- Prepared Definition of Ready and Definition of Done checklists.
Total Story Points: 48
