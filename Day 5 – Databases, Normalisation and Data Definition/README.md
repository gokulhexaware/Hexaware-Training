Day 5 

This repository contains three sets of tasks completed using Microsoft SQL Server and MongoDB.

Set 1 – Retail Inventory and Product Reviews

Database Name: retail_inventory

This set focuses on retail inventory and product review management, including suppliers, categories, warehouses, products, and inventory. It covers database normalisation up to 3NF, ER diagrams, primary keys, foreign keys, UNIQUE constraints, CHECK constraints, DEFAULT constraints, referential actions, INSERT, UPDATE, DELETE, and MongoDB product reviews with schema validation.

Set 2 – Bank Branch Accounts and Customer Activity

Database Name: bank_branch_accounts

This set focuses on banking account management and customer activity, including customers, bank branches, accounts, and transaction activity. It covers database normalisation up to 3NF and BCNF, candidate keys, composite keys, IDENTITY columns, CHECK constraints, UNIQUE constraints, DROP, TRUNCATE, DELETE, data manipulation, filtering with WHERE, AND, OR, IN, BETWEEN, and MongoDB capped collections for customer activity logs.

Set 3 – Hospital Patient Records and Clinical Notes

Database Name: hospital_records

This set focuses on hospital patient record management, including patients, doctors, departments, visits, billing, and clinical notes. It covers database normalisation up to 3NF, table decomposition, primary keys, foreign keys, constraints, ALTER TABLE, renaming tables, dropping constraints, and MongoDB clinical notes.

Technologies Used:
- Microsoft SQL Server 
- MongoDB
- MongoDB Shell (mongosh)

Each set contains separate SQL Server and MongoDB scripts with database structures, sample data, and practical database operations.

The purpose of this practice is to understand database fundamentals, normalisation, relational database design, constraints, data definition, data manipulation, SQL Server operations, and MongoDB collection management.
