Python Track – Day 1: Problem Solving Techniques and Data Structures

A collection of Python implementations completed as part of the Day 1 assignment, covering searching algorithms, sorting techniques, data structures, hashing, greedy algorithms, divide and conquer, and dynamic programming.

Sets Completed

Set 1 – Retail Order Desk

Focused on managing retail orders through searching, sorting, duplicate detection, and efficient data structures.

Topics Covered:
- Linear Search and Binary Search on 50,000 order records
- Bubble Sort and Merge Sort for ranking orders by amount
- Performance comparison with Python's built-in sorting
- Duplicate order detection using hash-based structures
- Stack implementation for undoing order edits
- Queue implementation for dispatch management
- Greedy Algorithm and Dynamic Programming for minimum currency change

Set 2 – Retail Banking Transaction Review

Focused on transaction searching, statement sorting, duplicate posting detection, and transaction analysis.

Topics Covered:
- Binary Search and Linear Search on 100,000 transaction IDs
- Best, average, and worst-case comparison analysis
- Insertion Sort and Merge Sort for sorting bank statements
- Stable sorting and handling transactions with identical timestamps
- Duplicate transaction detection using hashing
- Queue implementation for manual-review backlogs
- Stack implementation for reversing the last adjustment
- Divide and Conquer for finding minimum and maximum transaction amounts

Set 3 – Hospital Appointment Desk

Focused on patient record searching, appointment scheduling, duplicate booking prevention, and appointment optimization.

Topics Covered:
- Linear Search and Binary Search on 20,000 patient records
- Performance measurement for 1,000 patient look-ups
- Selection Sort and Quick Sort for appointment prioritization
- Comparison of sorting swaps and execution time
- Double-booked appointment detection using hashing
- Queue implementation for walk-in patient management
- Stack implementation for recently viewed patient history
- Dynamic Programming for maximizing the number of appointments
- Greedy approach comparison for appointment scheduling
