Set 1 – Retail Order Desk

Completed all five tasks using Python, covering searching algorithms, sorting techniques, hashing, stacks, queues, greedy algorithms, and dynamic programming.

The tasks include Linear Search and Binary Search, Bubble Sort and Merge Sort, duplicate order detection using hashing, custom Stack and Queue implementations with built-in comparisons, and minimum coin calculation using Greedy and Dynamic Programming.

Each task includes Python implementation, sample output, time complexity, space complexity, and data-structure rationale.
