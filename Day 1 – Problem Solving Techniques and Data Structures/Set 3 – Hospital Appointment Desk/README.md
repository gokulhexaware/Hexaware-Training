Set 3 – Hospital Appointment Desk

Completed all five tasks using Python, covering Linear Search, Binary Search, Selection Sort, Quick Sort, duplicate appointment detection using hashing, Queue, Stack, and Dynamic Programming.

The tasks include searching patient records, sorting appointments by urgency and arrival time, detecting double-booked appointment slots, managing walk-in patient queues and recently viewed patient history, and finding the maximum number of appointments a doctor can attend during a shift.

Each task includes Python implementation, sample output, time complexity, space complexity, and data-structure rationale.
