Problem Solving Techniques and Data Structures – II

A collection of Python solutions focused on applying data structures and problem-solving techniques to real-world business scenarios.

This assignment covers three different domains: E-Commerce, Insurance Claims Processing and Logistics Network Management.
Set 1 – E-Commerce Catalogue and Traffic Analysis

Focused on managing product categories, SKU lookups, microservice dependencies and customer traffic analysis.

Tasks Covered

1. Binary Search Tree
   - Created a BST containing 15 product categories.
   - Implemented insertion and searching.
   - Performed inorder, preorder and postorder traversals.

2. Hashing and HashMaps
   - Implemented a hash table using chaining.
   - Demonstrated collision handling.
   - Compared custom hash table and Python dictionary lookup performance for 100,000 SKUs.

3. Graphs
   - Represented microservice dependencies using a directed graph.
   - Implemented BFS and DFS-based topological ordering.
   - Detected circular dependencies.

4. Sliding Window
   - Analysed requests-per-minute data across 24 hours.
   - Identified the busiest continuous 3-hour window.

5. Two Pointers
   - Identified order-value pairs matching a given gift-card value.
   - Used a sorted list for efficient pair searching.

Set 2 – Insurance Claims Processing

Focused on claim management, duplicate detection, approval workflows and regional claim processing.

Tasks Covered

1. Binary Search Tree
   - Created a BST to store claim IDs.
   - Implemented insertion and searching.
   - Displayed all three tree traversals.
   - Identified inorder traversal as the sorted traversal.

2. Hashing
   - Detected duplicate and near-duplicate claims.
   - Used policy numbers and incident dates as hash keys.
   - Handled differences in letter case and spacing.
   - Explained collision handling.

3. Graphs
   - Represented insurance approval stages using a directed graph.
   - Implemented BFS to find the shortest path.
   - Used DFS to detect circular dependencies.

4. Sliding Window
   - Identified the longest consecutive run of days with more than 100 claims.
   - Used the sliding window technique for efficient processing.

5. Two Pointers
   - Merged two sorted claim lists from different regional offices.
   - Preserved duplicate claim IDs.
   - Avoided additional sorting.

Set 3 – Logistics Network and Delivery Windows

Focused on hub management, parcel tracking, route optimisation and delivery-window analysis.

Tasks Covered

1. Binary Search Tree
   - Stored hub codes using a BST.
   - Implemented insertion and searching.
   - Calculated tree height.
   - Compared tree height for different insertion orders.
   - Analysed the effect of sorted input.

2. HashMaps
   - Created parcel tracking lookup using a Python dictionary.
   - Detected parcels scanned multiple times at the same hub.
   - Used tracking numbers and hub codes for duplicate detection.

3. Graphs
   - Represented 10 logistics hubs using an adjacency list.
   - Implemented BFS to find the route with the fewest hops.
   - Used DFS to identify all hubs reachable from the central depot.

4. Sliding Window
   - Analysed hourly parcel counts.
   - Identified the 4-hour window with the highest average.
   - Used an efficient sliding window approach.

5. Two Pointers
   - Checked whether delivery route descriptions are palindromes.
   - Ignored letter case and separators.
   - Compared characters using two pointers.
