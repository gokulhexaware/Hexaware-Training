Python Track – Day 11 | Python 3.13

Introduction and Control Statements

This repository contains the three assignments completed as part of the Hexaware Python Training Program – Day 11.

The assignments focus on Python 3.13 fundamentals, conditional statements, pattern matching, loops, operators, type hints and exception handling through practical business scenarios.

Assignments

Set 1 – Loan Eligibility Engine

Developed a loan eligibility system that evaluates applicants based on age, monthly income, EMI ratio, credit score, employment type and existing loans.

Key concepts:
- If-elif and nested conditions
- Match/case statements
- Type hints and dataclasses
- For loops, break and continue
- Loop-else
- F-strings
- Input validation and edge-case handling

Files:
- main.py
- driver.py
- TEST_CASES.md

Set 2 – Utility Billing Calculator

Developed an electricity billing application that calculates customer bills based on consumption slabs, consumer categories, late-payment surcharges and online-payment rebates.

Key concepts:
- Four electricity consumption slabs
- If-elif statements
- Match/case statements
- Arithmetic and operator precedence
- For and while loops
- Break and continue
- F-string formatting
- Input validation

Files:
- main.py
- TEST_CASES.md

Set 3 – Insurance Premium Bands

Developed an insurance premium calculation system based on applicant age, BMI, smoking status and policy term.

Key concepts:
- BMI calculation and classification
- Nested if statements
- Match/case with guards
- Arithmetic, comparison and logical operators
- For loops, break and loop-else
- Type conversion
- ValueError handling
- Dataclasses and type hints

Files:
- main.py
- TEST_CASES.md

How to Run

Open the required assignment folder in VS Code.

Create and activate its virtual environment:

py -3.13 -m venv .venv

Windows PowerShell:

.\.venv\Scripts\Activate.ps1

Run Set 1:

python driver.py

Run Set 2:

python main.py

Run Set 3:

python main.py
