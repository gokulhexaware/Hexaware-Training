Day 7 

This repository contains three sets of database practice tasks completed using Microsoft SQL Server and MongoDB.

Set 1 – Logistics and Shipments

Database Name: retailsales

This set focuses on logistics and shipment management, including database creation, data insertion, data retrieval, filtering, and MongoDB operations.

Set 2 – Bank Loan Portfolio

Database Name:  BankLoanPortfolio
This set focuses on banking and loan management, including customer and loan data, SQL queries, joins, aggregations, subqueries, and MongoDB operations.

Set 3 – Retail Returns and Refunds

Database Name: retailreturnrefund

This set focuses on retail stores, customers, products, employees, sales, returns, refunds, and customer feedback. It includes SQL joins, self joins, IN, NOT IN, EXISTS, NOT EXISTS, ANY, ALL, nested subqueries, and MongoDB aggregation using $lookup.

Technologies Used:
- Microsoft SQL Server 
- MongoDB
- MongoDB Shell (mongosh)

Each set contains separate SQL Server and MongoDB scripts.

The purpose of this practice is to improve database management, SQL query writing, data analysis, joins, subqueries, aggregation, and practical database problem-solving skills.
