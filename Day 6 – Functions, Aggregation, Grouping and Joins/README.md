Day 6 

This repository contains three sets of tasks completed using Microsoft SQL Server and MongoDB.

Set 1 – Retail Sales Reporting

Database Name: retailsales

This set focuses on retail sales reporting, including orders, order items, customers, and products. It covers revenue analysis, monthly sales, top-selling products, customer order analysis, average basket value, aggregate functions, grouping, and MongoDB aggregation pipelines.

Set 2 – Insurance Policy Reporting

Database Name: insurancepolicy

This set focuses on insurance policy management and reporting, including customers, policies, premiums, agents, and claims. It covers policy expiry analysis, premium collection, claim ratios, active policies, age-based reporting, date functions, CASE expressions, and MongoDB aggregation.

Set 3 – Telecom Usage and Billing Reporting

Database Name: telecombilling

This set focuses on telecom usage and billing analysis, including subscribers, plans, call records, and invoices. It covers call minutes, data usage, monthly revenue, overdue invoices, average revenue per user (ARPU), plan popularity, NULL handling, and MongoDB aggregation pipelines.

Technologies Used:
- Microsoft SQL Server
- MongoDB
- MongoDB Shell (mongosh)

Each set contains separate SQL Server and MongoDB scripts with sample data and reporting queries.

The purpose of this practice is to improve database management, SQL functions, aggregate functions, GROUP BY, HAVING, joins, data analysis, and MongoDB aggregation skills.
